# Happy Birthday Yara

A static birthday website ready for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — design and animations
- `script.js` — navigation and interactions
- `background1.jpg` — home background
- `background2.jpg` — inner pages background
- `birthday-song.mp3` — birthday song

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will give you a public website link.

Keep `index.html` in the repository root so GitHub Pages can load it automatically.
